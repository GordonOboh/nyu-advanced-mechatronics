## The Projects

### 1. The Arduino Robot
A line-following robot using an Arduino Nano with QTR-8RC sensor array and ultrasonic object detection.

### 2. The Propeller Robot
Multi-core line-follower with obstacle avoidance, powered by a Parallax Propeller and Arduino Nano.

### 3. The Term Project — Friend or Foe?
Computer vision robot with Raspberry Pi + camera for ArUco marker detection and friend/foe classification.
